# v0.1.0 UI/UX 交接

日期：2026-10-11。主设计：[03_UIUX设计.md](03_UIUX设计.md)。状态：设计完成；实现和体验核验待进行。

## 前端

- 地图工具首屏：桌面72px顶栏、336px墨绿/石板侧栏、清晰大底图；搜索/地区/完成筛选/DLC快捷开关；侧栏下方安全预览。<900px改底面板，收起56px，展开≤可用高度60%，按钮可收起，360px和44px目标可用。
- 路由：`#/`、`#/shrine/:id`、`#/settings`。独立详情默认关闭详细前置、物资宝箱、攻略三节；换神庙或返回地图后重置关闭，语言切换保留当前展开。
- incomplete/complete/selected同时用颜色与图形区分；r2取消所有聚合和附近分组，近景逐座显示，远景只显示高塔。列表始终定位同ID并强制近景。地图/列表不要奖励、解锁或攻略内容。
- 用专用safe对象呈现外层；不要截断detail作摘要。名称/地区/范围/坐标/完成、`safe.summary`安全介绍、`safe.prerequisite`简短前置、字段核实标签可见；缺依据显示待核实。
- 语言、DLC和进度分离。三语名称与地区都可搜索；完整字典含错误、备份、范围计数及缺译；菜单显示各语言自己的名称。
- 切换视图保存center/zoom/query/regionId/completionFilter/selectedId。返回恢复视角与有效选择，发起控件存在时恢复其焦点，否则搜索；路由新页聚焦标题。
- DLC两入口即时同步持久化，136↔120；隐藏不删完成ID。隐藏选中的DLC则清预览；已在详情保留并提示地图隐藏，不跳页。

## 技术

- hash路由与MapContext已经对齐；safe/detail独立合同、稳定ID、源坐标映射、三语资料/核实标签仍由技术方案定义。
- 存储失败保留当前会话，常驻提示未保存，可重试或导出；不显示成功。备份包括隐藏DLC，导入校验→预览→明确恢复；未知ID可见，失败/取消不变更现有进度，保留导入前备份。
- 底图失败保留列表，数据失败显示重试而非0座；source线上失败仍展示已核实本地版本。缺内容/缺译不能冒充完整。

- Tab/Enter/Space可操作全部主流程；地图方向键/缩放可用或具备列表定位+缩放/全图替代；输入内不截获。返回恢复发起焦点，导入对话框有完整焦点管理。

## r2 增量交接

- 用户验收退回修改，依据01的R8–R10/A8。暂按连续缩放下两档显示层：远景只有15座真实高塔；近景只有当前筛选的神庙。没有cluster数字、附近分组、展开重排或坐标偏移。
- 当前CRS.Simple/3000×2500底图统一`z=-1.0`为分界，缩放完成后切层；滚轮、双指、+/−仍连续。用户若选固定两级再调整。
- 神庙主图形16–20px，建议18px；透明hitbox≥44px。完成小勾、选中细环，状态不放大。交叠命中区按最近真实中心选取，列表提供同ID定位，不恢复附近分组。
- 点高塔或列表神庙：居中并至少到近景，`NEAR_FOCUS_ZOOM=-0.5`，实际取`max(当前zoom,-0.5)`；手机按露出的地图区域居中。高塔只定位，不计神庙进度、不标完成、不接详情攻略，不新增页面。
- 全图回远景；缩回远景可保留神庙选择/安全预览但隐藏神庙点，再放大恢复。语言、DLC、详情返回和持久进度按原合同；远景15塔不受神庙筛选影响。
- 三语远景标签“放大地图查看神庙 / Zoom in to see shrines / 拡大すると祠が表示されます”；高塔名称真实三语。移动端无需hover即可理解塔可点击，双指缩放不误选。
- QA检查阈值上下、远→近→远、高塔点击、远景列表选择、手机面板遮挡与三语/DLC；全程无聚合/nearby，完成分母仍为120/136，safe边界保持。

## r3 增量交接

依据03第11节、01的R11/A9与[evidence/r3/user-hover-before.png](evidence/r3/user-hover-before.png)。用户确认连续缩放按阈值切层；hover外观退回修订，尚未整版验收。

- 前端：神庙提示拆成名称、地区、底行两个状态badge；高塔为名称、地区、定位短提示。名称13–14px/600/1.4，地区12px/1.4，标签11px/1.2，系统无衬线属性分别明确。名称与地区各一行ellipsis，marker的完整三语基础`aria-label`保留。
- 卡宽优先220px，200–240px可按真实文本微调；显式宽度或`max-content`加下限，最大不超实际可见地图宽−24px。约10px内边距、4–6px行间、细墨绿卡边框、轻阴影；正常三行约80–95px，不固定高度、不做宽长条。`pointer-events:none`；底行无操作按钮。
- 首选点上，顶边不足翻下；按地图实际矩形夹紧，四边目标12px。608px窄屏、360/390px手机的底界须截到`.sidebar`实际顶边，随面板开合/resize/地图运动重算；不得仅按整个Leaflet容器高度定位。点位在面板后或可见区外则不展示卡片。箭头无法保持正确指向时可隐藏。
- QA：检查1440、608、360、390px，三语/长英文名/四边/面板顶边及开合；用户反馈的诺基·米席是`Dungeon052`，`Dungeon051`为卡玛·拉席，两者勿混记。覆盖本体/DLC、完成/未完成、高塔；用实际宽高和computed style确认不再单字竖栏、字体正确、卡完整可见。
- 只使用基础安全字段；不带试炼名、详细前置、解法、奖励、宝箱。18px/44px、无聚合、阈值和资料/进度维持现有合同。旧CSS只是原因线索，根因及修复结论由浏览器证据支持；本交接仅设计输入，不代签QA或本人验收。
