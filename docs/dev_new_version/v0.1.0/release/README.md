# v0.1.0 已验收构建归档

此归档保存用户验收通过的r3静态构建，包含入口、JS、CSS、底图、神庙数据和第三方许可，共6个文件。文件及ZIP哈希见[manifest.json](manifest.json)，验收原话见[用户验收记录](../08_用户验收.md)。

## 本机使用

当前项目预览保持在 http://127.0.0.1:5173/ 。重新运行项目时，在项目根目录执行 `npm install`、`npm run dev`；生产构建预览可执行 `npm run build`、`npm run preview`。dev与preview使用同一固定端口，择一运行。

ZIP是构建备份。解压后需通过HTTP静态服务器访问，资源从根路径加载。当前项目源代码及研究资料仍保留在工作目录；归档不包含浏览器个人进度，进度请在设置页单独导出。

交付范围为本机使用。此次没有公开部署或Git远端发布。
