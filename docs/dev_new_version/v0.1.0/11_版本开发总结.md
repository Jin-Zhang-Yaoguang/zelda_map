资料采集需验证真实文章节点，而非把HTTP成功当有效正文。地图展示使用单独safe合同，避免摘要截断泄漏。小数zoomSnap使全图适应可见尺寸；透明命中区与视觉尺寸分离；定位高塔与保留神庙选中须明确定义。旧源码、r1报告与失败证据均保留，可追溯修订原因和效果。

## r3 悬浮提示修订

用户附图指出hover内容难看。独立基线实测旧提示只有34px宽、414px高，文字逐字换行；父Leaflet pane不提供可用宽度，旧CSS只限制最大宽度且字体简写无效。

本次应用改动只在MapCanvas与styles：明确220px横向卡宽、有效字体属性、名称/地区/状态三层信息；长名称省略，完整基础信息保留ARIA；游戏文字使用textContent，卡片不拦截地图点击，不增加剧透字段。可见地图边缘定位同时考虑控件和手机面板。

独立QA发现一个真实增量缺陷：开启卡片时键盘平移使点位离屏，卡片仍钉在边界。前端补充可见点位判断，离屏关闭，并只在提示开启时注册地图/面板尺寸监听，关闭/移除时统一清理。修后真实操作通过；早期四边测试的控件遮挡和动画时序问题与业务缺陷分别保留，最终操作先确认实际命中目标点位。

本次独立UI复核、前端实现、QA与看门狗均实际参与。4种视口的96个核心卡片组合及24个边缘位置通过；构建与26项独立静态/包读回通过。具体命令、源码绑定、失败历史及设备限制以本轮07/09为准。本机预览继续运行，用户本人已确认hover效果并通过整版验收。
