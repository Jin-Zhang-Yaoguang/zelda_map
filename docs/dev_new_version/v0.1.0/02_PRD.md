## 2. 目标与范围

玩家能在真实海拉鲁地图中查找神庙，先看最低限度的入口信息，需要帮助时主动进入本站详情，并记录自己的完成进度。

本版收录BOTW全部136座神庙：本体120座、DLC16座。Zelda Dungeon的travel gates分类只作采集线索；高塔、复苏神庙和其他传送点不得计入神庙总数。默认显示本体+DLC，独立设置页面可关闭DLC，地图提供同步的快速DLC开关。

r2增加15座Tower作为远景定位层，仅显示真实位置、三语名称与地区。近景显示独立神庙，远景隐藏神庙并只显示Tower。Tower不新增完成状态、攻略模块或神庙总数。

非目标：王国之泪、呀哈哈、其他物件（上述Tower定位层除外）、路线规划、自动读取游戏存档、账号、云同步、收费与公开部署。首版仅本机预览。

默认简体中文，另有English／日本語。中文字形是产品默认选择，可随用户反馈调整；不额外承诺繁体中文。

## 4. 不剧透边界

地图提示、预览卡、列表、搜索结果、筛选标签、鼠标悬浮和键盘焦点提示都是“外层”。进入本站详情是用户主动查看更完整信息的边界。

| 字段 | 外层 | 本站详情 |
| --- | --- | --- |
| 收录名称、地区、本体/DLC、真实坐标、完成状态 | 可见 | 可见 |
| 基础介绍 | 仅已核实的所在环境与一般用途；不描述机关操作、隐藏入口操作或故事结果 | 可完整介绍 |
| 简短前置 | 已核实的类别概述，如“需先完成相关神庙挑战”“需推进DLC相关任务”；不列操作、答案、交付物或剧情结果 | 可列任务名、依赖关系、准备条件与解锁步骤 |
| 物资、宝箱位置/数量/内容、通关奖励 | 不显示 | 仅详情可见 |
| 谜题答案、操作步骤、战斗打法、解锁操作、攻略截图 | 不显示 | “查看攻略”区可展开 |
| 来源链接 | 可显示来源站名；外层主入口进入本站详情 | 可打开外部参考，注明“可能剧透” |

详情默认显示基础介绍；详细依赖、物资、攻略为独立折叠区。返回地图或进入另一座神庙时重新折叠。完成按钮无需展开攻略即可操作。

任何能直接告诉玩家“做什么便能出现神庙、解开机关或取得宝箱”的内容都放入详情。前置本身包含解法时，外层只写类别。三语遵守同一语义边界；搜索只匹配名称和地区，不检索攻略、奖励或详细前置。

“未核实”不等于“无前置”或“无物资”。缺依据时显示“待核实”，可信来源链接可帮助继续查询，但不能算字段完整。通用提示可作说明，不能冒充逐座攻略。外层、详情及其三语译文应从不同安全等级字段读取，不得把全文截断当作安全摘要。

## 5. 主流程、设置与状态

### 5.1 查找与详情

打开应用 → 读取语言、DLC设置及完成记录 → 加载底图与数据 → 拖动/缩放，或搜索/筛选 → 点击点位/列表进入安全预览 → 点击“查看详情”进入本站独立视图 → 主动展开详细依赖、物资或攻略 → 返回原地图上下文。

列表选择定位地图并选中同一ID；若当前是远景，自动进入能显示该神庙的近景档，不要求用户自己继续放大。空结果显示当前条件与清除入口。条件变化隐藏当前选中神庙时，清除外层预览。合法详情ID可直接访问；不存在的ID显示未找到及返回入口。

### 5.2 设置页与DLC

设置是本站独立页面，有明确返回地图入口。至少包含语言、DLC显示开关和进度备份入口。地图可快速调整DLC显示，两个入口共用同一偏好并持久化，刷新后保持。

DLC开启时范围是136座，关闭时是120座。关闭只影响地图点位、列表、搜索结果和当前范围进度分母；DLC的已完成ID仍保留在存储和备份中。重新开启立即恢复其状态，开关往返不丢数据。关闭时正选中DLC神庙，清除地图预览；若当前在其详情，继续显示该详情并提示“DLC已在地图隐藏”，返回后按设置过滤。开关操作不强制跳页。

范围进度按当前DLC设置计算，界面注明“本体”或“本体+DLC”；搜索/地区/完成筛选的结果另显示“当前结果已完成/当前结果总数”。数据目录始终是136座，不能把隐藏后的120座说成数据缺少。

### 5.3 完成与保存

完成表示用户确认已通关，只有未完成/已完成两种状态。发现、开启传送点、阅读攻略不自动完成；依赖提示不阻止用户手动标记。标记/取消后保存并同步各视图，重复操作不重复计数。语言、DLC开关、筛选和折叠状态不改完成ID。

正常保存后刷新读取相同浏览器、相同本机地址的状态。页面说明“进度保存在当前浏览器”。浏览器存储被禁用或读写失败时，仍可浏览并保留本次会话操作；明确提示“本次进度未能保存”，导出仍可使用，不显示保存成功。稳定启动地址与端口由技术方案定义。

### 5.4 备份

导出JSON至少含格式版本、游戏标识、数据版本、导出时间、完成ID集合；包括当前隐藏的DLC完成记录，名称和语言不作身份键。

导入先校验格式、游戏、版本和ID，再预览将恢复的完成数与未知ID数。用户在应用内点击“恢复备份”后替换完成集合，保留导入前备份；取消或校验失败不变更进度。未知ID不静默丢弃，显示明细并允许取消，不计入进度。导入前备份方式由技术方案规定。备份内容按数据处理，不作为HTML执行。

### 5.5 r2缩放显示

当前实现假设是连续缩放加一个显示阈值T：小于T为远景，只用15座Tower定位；达到或超过T为近景，只用独立神庙点位。T的具体值由设计/实现记录，测试验证边界。此假设尚未获得用户对“连续/固定两级”的选择，不把固定两个zoom写成已实现或已确认。

神庙图标相对r1缩小视觉尺寸，保留原可点击范围和键盘/列表路径。任何zoom下均无聚合数字、cluster节点、nearby聚合选择或按位置合并的入口；神庙坐标不因防重叠而改写。重叠点位仍可通过完整列表选择。

神庙的搜索、地区、完成及DLC条件继续作用于神庙列表和近景点位；远景Tower层不因这些神庙条件删减，其全图数据固定15座。缩放不改变列表结果、进度分母或完成ID。缩至远景只隐藏神庙地图标记，保留selectedId及安全预览；列表选神庙会回到近景。点高塔作为新的定位动作应清除旧神庙选择和预览，再进入近景；不清除原有筛选。

点击Tower最多显示名称、地区、坐标等定位信息，不出现神庙完成按钮，不跳到神庙详情。语言切换只改Tower文字，不改ID或点位；Tower与神庙的ID、类型与渲染入口分开，进度及备份只接受神庙ID。

## 6. 数据与三语口径

每座使用一个跨语言稳定ID，保留来源ID映射。必需字段：游戏、范围、地区、来源坐标与底图定位、三语名称、安全介绍、简短前置、详细介绍、详细依赖、物资、专属攻略、来源引用和核实状态。

坐标是游戏/地图坐标，不冒充地理经纬度。像素/归一化坐标保留原值及投影转换，点位可复算。地区采用统一来源分区；DLC仍记录实际所在地区。

事实字段记录来源URL、采集日期、页面/字段定位及核实状态，不同字段可有不同来源。Zelda Dungeon为主要交互与数据参考；不可读取的公开页面不绕过限制，使用可核查替代来源并记录差异。中文、日文名称对应可信游戏文本或多语资料，不把自行音译标为“官方译名”；未证实的名称标“暂译/待核实”并保留原名搜索。本站自译说明标为译述，不改事实。

三语验收覆盖界面、名称、地区、安全介绍、简短前置、详细介绍、依赖、物资和攻略。回退可保障浏览，但须显示缺译并计入缺口；只有按钮翻译、整段回退英语或136座重复同一模板都不算完整三语。相同类型可共用结构，地点、进入条件、物资、攻略仍逐座核实。没有记录与已核实无额外物资是不同状态。

保留来源快照或可复查采集记录、转换脚本/步骤、字段映射及数据版本。生成数据不能作为自身正确性的唯一证据。逐座详情能追溯专属来源，以本站整理/译述呈现事实，避免整页原文复制。来源在线失败时仍能展示已有、注明版本的本站内容。

## 8. 例外、风险与接力

- 136座三语专属内容是主要工作量；可先给可运行预览，但必须列缺口，不能改称完整攻略版。
- 本机地址/端口变化可能改变存储来源；备份用于迁移，启动方式应稳定。
