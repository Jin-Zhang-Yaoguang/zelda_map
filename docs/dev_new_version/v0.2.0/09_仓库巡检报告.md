## 源码与事件链

- `StableMapTiles`只扩展Leaflet公开getEvents，删除viewprereset全销毁绑定；安装的Leaflet1.9.4实现每次返回独立对象，zoom/viewreset/moveend及卸载仍保留。继承TileLayer的_abortLoading只移除不同原生tileZoom的未完成片，不是每次同级缩放全清。没有覆写私有渲染/鉴权逻辑；实际tile DOM复用仍以浏览器结果证明。
- CRS.Simple/u/v/bounds保持，普通tile256/offset4、高密tile128/offset5正确映射本地source2..7；DPR1最大显示源6，高密最大源7。没有用源像素尺寸代替逻辑世界尺寸，不上采样或重绘声称新增细节。
- helper关闭原wheel等待和zoom动画，每rAF只应用累计输入/最后指针，以公开setZoomAround即时更新；先按zoomSnap取整，细输入残余保持且未跨步长不平移。min/max夹紧，ctrl/meta、控件与零垂直量不截获；外部移动/触摸/卸载取消帧并解绑，原触摸/键盘handler保留。
- Marker池按ID复用。筛选只处理受影响ID，选择/完成只更新对应icon/说明，不按zoom清图层。两pane显隐不删除所有marker，hover监听仅打开时挂载，关闭/remove/dispose取消rAF/observer/事件，更新说明不重复绑定。纯DOM文字只用名称、地区、范围/完成状态，不引入解法/物资剧透。
- 两类型点击使用当前显示候选和实际中心距离，44px hit不移动点位，同中心保持实际命中类型。先前静态担忧“隐藏旧事件无附近候选时fallback第一项”未成为复现缺陷：QA实际pointerdown→关闭→pointerup检查无phantom选择/塔聚焦。仍只覆盖这条实际事件排列，不声称所有合成延迟事件全覆盖。
- showShrines默认true；旧schema1缺字段以ready读回true，显式false保持，非法类型corrupt且原raw保留。侧栏开关位于DLC上方，与设置页共用保存；只隐藏地图pane，列表、查询结果、选中、计数、导入导出/UID进度不删除。神庙所有zoom受原DLC/搜索/地区/完成筛选，塔按旧阈值远/近显隐；四图例一致。神庙symbol/svg36、选中圈40、hit44、列表20、塔22×26分别保留。
- 高清失败隐藏broken img，保留概览，compact提示与重试不阻断标记或进度；成功/卸载清对应失败key。概览重试成功才替换旧图，销毁先解绑tile监听，避免卸载事件回写React状态。

## 真实测试及性能边界

独立QA共14个唯一浏览器组：marker六组全部pass，覆盖全zoom/仅地图开关与刷新、DLC独立与尺寸、重叠最近神庙命中/136节点复用、旧/坏/false偏好、三语窄屏hover、隐藏期间原生pointer序列无phantom。跨类型/同中心分发仅静审，没有全类型同中心DOM fixture。HD/input八组有最终通过证据：DPR1/2首轮错误selector造成失败，原结果保留；首轮T03只测container，已撤回其tile复用含义。hd-targeted的DPR1源6/DPR2源7+世界几何及真正tile DOM复用三组通过；原其他滚轮/故障恢复结果保留，hd-small-touch新增细输入残余及模拟双指两组通过。模拟pinch不是实体手机/Safari验收，错误修正不冒称实现修复。

`zoom-first.json`是同16次deltaY24、间隔16ms输入的本机观测：near首次可视约49.2→7.6ms，far49.5→7.5ms；baseline各2次zoom更新、candidate各11次；跨阈值候选不新增/删除marker。两者均0个>32ms帧，不能据此说FPS提高。candidate near p95帧约16.6ms、最大25ms，baseline p95约8.8ms。相同输入终点不同（near-.4→.3，far-2.2→-2.9），且far可见151对15，属于不同滚轮增益/相机轨迹/负载的响应观测，不是等轨迹GPU性能对照，更不能代替用户实际滚轮/触控板手感验收。

QA构建和浏览器用隔离context、未配置访客envFile:false及明确测试harness；页面测试不是本角色操作真实用户浏览器或真云联调。旧r2真实API10组、r3邮箱行为和未变账号守护保留原范围；r4没有再注册/删除用户或重复云SQL。最终07列出实际覆盖与未测条件，不沿用旧远景只有塔断言。
