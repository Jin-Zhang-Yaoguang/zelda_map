# v0.1.0 需求基线

日期：2026-10-11。首版版本号经用户确认 v0.1.0，本机预览。

## 用户原文

「以《Zelda Dungeon 互动地图》为主要参考，做个中文版本地图。能实现中、英、日语言切换。采用dev new version开发。第一阶段只围绕神庙（对应traverl gates）模块，能给出所有神庙位置，在大地图上能给出每个神庙介绍、前置依赖等，点击链接进入详情（外部不剧透原则)，能看到神庙介绍、物资、通关攻略等内容。对神庙可以标记完成」

## 已明确的范围

- R1：以 Zelda Dungeon BOTW 地图为主要交互参考，展示海拉鲁真实地图与神庙位置。
- R2：中文默认语言，可切换英语、日语。界面、名称与说明纳入语言范围，不能仅切换按钮标签。
- R3：神庙为本版唯一游戏内容模块；排除王国之泪、呀哈哈、其他传送点或复苏神庙混入神庙完成总数。
- R4：地图点击神庙后显示基础介绍、所在地区和简短前置条件；不在地图、列表、搜索结果透露具体解法、奖励或宝箱。
- R5：点击进入本站独立神庙详情视图，显示介绍、依赖、物资和通关攻略；详情中的详细解法可再折叠展开。外部参考链接明确标注可能剧透。
- R6：可标记/取消完成，刷新页面保留状态，同一稳定神庙 ID 在语言切换后共用进度。

## 首版建议与待确认

- 本体 120 座、DLC 16 座，共 136 座；用户已确认收录全部，并明确要求设置页面，DLC变更可快速筛选。依据：https://www.zeldadungeon.net/breath-of-the-wild-walkthrough/shrine-locations/ 。
- R7：独立设置页面可切换 DLC 显示范围，偏好持久保存；隐藏 DLC 不删除完成记录。
- 交付为本机可运行版本，不推送或部署。用户确认原话：「按 v0.1.0 做本机预览」。
- 完成状态先保存于当前浏览器，提供备份导入/导出。用户原始用途为个人使用，跨设备账号同步不纳入首版。

## 可观察验收条件

- A1：名单数量、稳定 ID、真实坐标、地区及中英日名称完整，能与来源核对，来源与生成脚本保留。
- A2：地图支持拖动缩放，神庙点位与真实地图地标相符，点击点位和列表指向同一神庙。
- A3：三语切换覆盖 UI 与神庙内容，搜索可匹配三语名称，切换保留所选神庙与完成状态。
- A4：地图外层不显示物资和谜题解法，独立详情提供各神庙真实内容及来源，不能用重复泛化文本冒充专属攻略。
- A5：完成、取消、刷新、筛选、导入导出与异常存储均有实际验证。
- A6：桌面与手机可操作，数据/底图失败有可见错误和恢复入口，键盘可进入详情与标记完成。
- A7：设置页面切换 DLC 后地图、列表与范围计数同步更新；刷新后保持设置，完成记录不丢失。

## 基线

工作目录原为空目录，无 Git 仓库、提交、源码或 WIP。初始化前以实际空目录为基线；不得虚构既有 SHA。版本开发、源码和验证证据保存在本项目。

开发过程中为满足技能的源码验收绑定，初始化本地 Git 仓库与 `dev/v0.1.0` 分支；仍无基线提交，未设置远端或推送。

## r2 用户验收反馈与修订

2026-10-11 用户原话：「用户验收反馈：优化点：1）缩小神庙在地图上的图标；2)在放大和缩小的过程中，神庙不要随着进行聚合，看起来很丑；3）可以设置正两档zoom，缩小到一定程度后只展示tower。」

该反馈为退回修订，并非候选验收通过。v0.1.0继续开发r2：

- R8：神庙视觉图标缩小，仍保留可点击/可通过列表选择的交互路径。
- R9：取消神庙点位聚合与聚合数字，在拖动和缩放过程中不重组神庙标记。
- R10：缩放远近两档展示：远景只显示15座高塔，近景显示神庙。高塔作为定位层，不新增完成状态或计入神庙总数。高塔使用公开游戏真实点位及中英日名称。
- A8：136座神庙近景单独显示，缩放无聚合数字与动态聚合；远景神庙不显示，高塔15座显示；阈值切换/三语/DLC/列表定位都正确。
- 两档暂按连续缩放下的显示阈值处理，已发可选澄清问题；若用户希望两个固定缩放级别，以其回复修订。
