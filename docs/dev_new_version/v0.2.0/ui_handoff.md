## 前端落点

- App：页眉下常驻身份/保存条，44px最小可操作区；进入设置账户节。身份和保存独立，长身份视觉省略、辅助名称完整。手机保留56px页眉，新增条进正常布局，地图resize/hover可见区重算。
- Settings：账户与同步 → 原显示 → 当前模式进度备份。缺配置明确说明，可正常guest。配置可用邮箱OTP+GitHub；account初始化前只读，不写guest、不把guest数计account。
- 表单：一个邮箱、一个可粘贴OTP；长度按实际配置，autocomplete和真实label/错误关联。发送/验证独立loading，错误保留输入，更换邮箱清验证码；回调恢复hash路由/语言。
- 迁移：目标身份完整；guest/account/result和重合计数；merge/replace不预选，逐座新增/取消；持久备份完成、原待同步/冲突清零才确认，guest保留。云变更重新预览；部分确认显示实际数量。设置可导出操作前快照、预览恢复；不同UID不能直接恢复账户快照。
- 冲突：名称/地区与小字稳定ID、每座本机/云值radio不预选，可逐座应用、稍后处理；二次变化清旧选，未处理队列保留。

## 统一状态

| 事件 | 表现 |
| --- | --- |
| guest持久确认 | 本机已保存 |
| account队列已持久，云未确认 | 同步中/离线待同步，不提前云成功 |
| 本机持久失败 | 本次修改未保存 + 重试/导出，优先于联网状态 |
| 初始化失败，无本UID缓存 | 完成/导入/迁移禁用；重试/退出可用 |
| 初始化失败，有本UID曾成功加载的可信缓存 | 标缓存及时间、不标最新；可离线编辑进本UID队列，恢复先校验版本；迁移禁用 |
| 空云 | 真实0，不清guest/UID缓存/队列 |
| UID切换/退出 | 旧撤销toast关闭；guest原值恢复，队列属旧UID |
| 会话失效 | 停云写、保留队列、重新登录，不转guest编辑 |
| 云全部确认 | 云端已同步；有冲突/队列不可出现 |

优先级：本机未保存 → 重新登录 → 冲突 → 同步失败 → 离线 → 同步中 → 云同步。设置保留其他待处理数；设置偏好与云进度状态分开。
