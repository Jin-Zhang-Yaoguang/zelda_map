## 删除GitHub后的行为与安全边界

- AccountPanel删除GitHub按钮和onGithub prop，App删除相关接线、OAuth视图schema/TTL/持久化/恢复及发起函数；Auth删除signInGithub、专属code兑换、return-hash与回调helper；types/controller删除可调用接口。三语GitHub状态词删除，普通登录/注册/继续访客保留。
- [watchdog-delta-review.json](evidence/r3/watchdog-delta-review.json)实际证明：controller相对r2逐字仅少GitHub调用一行，Auth两个邮箱方法逐字不变，client哈希不变。SDK通用PKCE/persistSession/autoRefresh设置保留，构建包包含SDK通用OAuth能力不等于产品存在GitHub入口；应用不自动交换旧code或使用旧视图数据，也不以删除用户旧storage/账户为前提。
- 真实session非空UID/token、error优先、无session诚实失败、密码原字符、注册最低8/登录非空规则保留。Auth凭据失败不将guest误标expired，Promise lifecycle/epoch/互斥、首次云初读屏障、旧UID队列/ACK、CAS/收据及持久备份链不变。
- App普通筛选/选中/面板初始化替代OAuth恢复，MapCanvas保持挂载并保留既有API空onView。ownerRef、UID key、焦点scope/epoch、readonly、完成操作及迁移/冲突/恢复触发控件守护沿用；不按邮箱/provider合并或删除原账号。
- 先前P3清表单旧认证提示仍保留：只忽略表单Auth类别，不修改snapshot和expired状态、云/storage/transfer警示。密码只在表单及认证调用；类型、队列、备份、导出、日志和环境变量没有新增密码路径。扫描是本机精确匹配，不替代真实磁盘取证或原生密码管理器验证。
