# v0.2.0 技术方案（当前 r4）

2026-10-11。基线 2686aa1，分支 dev/v0.2.0。用户取消 GitHub，仅邮箱注册/密码登录；主代理按已有专业方案收敛删除范围，前端代理统一负责六源码，独立 QA 与看门狗验证。r2 全文留在 revisions/r2，不再作为当前 GitHub 接入要求。

## 技术与身份契约

沿用 React/TypeScript/Vite/Leaflet SPA，Supabase SDK 2.117.3 负责身份，两个 PostgreSQL RPC 同步，IndexedDB 存账号缓存、队列与备份。语言/DLC偏好本机保存。136 神庙、15 高塔、无聚合与不剧透保留；高塔远近阈值保留，神庙改为所有zoom开关显示且符号36px。

公开 Auth 与 controller 只提供 `signUpEmailPassword(email,password)`、`signInEmailPassword(email,password)`、`signOut()`；Auth 返回有效 AccountIdentity，controller 返回 Promise<void>。删除 signInGithub、OAuth callback/code 兑换、return-hash、App OAuth 视图保存/恢复；不新增替代认证路径，不改官方 SDK 持久会话与现有 PKCE 配置。

只认真实 session 的非空 user.id/access_token；只有 user 或无有效 session 报 sessionNotEstablished，不猜测注册结果。明确 email_not_confirmed 才提示确认未完成。invalidCredentials、弱密码、明确重复、限流和网络错误分类保留。不用 Auth 裸 401 将访客标成失效；真实会话错误或 RPC 身份失效才暂停当前 UID 写入。

邮箱 trim，密码原样；注册最低 8、确认密码只在组件中校验，登录只非空。密码仅表单/请求内存，成功、切模式、身份变化、失效和卸载清除；不写快照、IDB、队列、备份、env或日志。编辑清本表单旧 Auth 错误，不掩盖身份/同步/存储/迁移错误。异步认证受生命周期与身份 epoch 保护，旧 Promise 不切回旧 UID。

AccountSnapshot 的 authPhase、ready、completedIds、saveState、pendingCount、conflicts、error、backups 不变。AccountIdentity 仍含 uid/email/provider/displayName，归属仅以 uid 决定；provider 为服务返回信息，不代表可用登录入口。前端不按邮箱合并账号。

## 同步与迁移（R3—R8 原契约）

- project/uid/game 分区缓存、队列与备份；访客使用原 v1 键，不把账号 Set 写回访客。退出恢复原访客，待同步项保留原 UID。
- 首次云读取成功前禁写；有同 UID 可信缓存才可离线编辑。异步结果必须仍属于当前身份。
- 完成/取消先持久保存缓存与队列，再发云；服务确认、队列清空且无冲突才显示 cloudSynced。网络、存储、限流与会话失效分别提示。
- RPC 使用 revision CAS/request UUID 收据；陈旧更新不能复活取消，重放不重复增版本。冲突逐座明确选择，再次远端变化必须重新选择。
- 访客/JSON/备份恢复先预览合并或替换；用户确认后，IDB 同事务保存原始备份与持久任务，再提交全部 136 项。批次冲突零进度写入，原访客字符串保留，隐藏 DLC 不漏迁移。
- 备份仅属于当前 UID；对话保留显式发起控件的返回焦点与身份 epoch 保护。

SQL 沿用 private shrine_progress/progress_receipts、RLS、owner policy、表直接 DML 禁止、仅 authenticated 可执行 SECURITY DEFINER RPC 与空 search_path。完整算法以源码和 migration 为准，不重复迁移、不建密码表/alias。

## r4 地图实现契约

Root负责真实原PNG镜像、scripts/collect_map_tiles.py、src/lib/mapTiles.ts、三语细节失败文案和源署名。前端负责MapCanvas与smoothWheelZoom/必要样式；独立QA执行当前构建与原r3同输入对比、坐标/细节/失败恢复，独立watch绑定源与资产。账号/Auth/SQL/数据内容不改。

原站源MapBase于commit9a937fa2888aaf4f0b40d021d2f8d87057f3c8d9声明maptex/{z}/{x}/{y}.png与maxNativeZoom=7；原MAP_SIZE=24000×20000。完整原PNG级别2..7计划9945张，逻辑u/v仍(X+6000)/4、(Z+5000)/4，不改神庙投影。PNG逐字节复制，验证256×256/CRC及hash，不重采样。完整成功后生成data/sources/map-tiles-manifest.json记录源URL/时间/原native尺寸/全部资产hash；镜像完成前不声称全部成功。

createMapTiles(pixelRatio)使用BASE_URL本地assets/map-tiles/{z}/{x}/{y}.png。普通屏tileSize256/zoomOffset4/minNative-2/maxNative3；高密屏tileSize128/zoomOffset5/minNative-3/maxNative2。应用min/max仍-4/2，noWrap/bounds保持原逻辑矩形；zoom0对应普通源4、高密源5，最大高密源7。概览overlay zIndex0，高清overlay zIndex2。

StableMapTiles只扩展公开getEvents，去viewprereset的全销毁绑定，仍处理zoom/viewreset/moveend与原卸载。原因：即时setZoomAround会触发Leaflet全局viewprereset；直接使用原TileLayer会每帧清空全部tiles。用官方更新路径复用当前层，按当前原生级别和可见范围增删，keepBuffer1，不扩大网格缓存。QA必须实测tile DOM/请求，不能只证明标记复用。

smoothWheelZoom关闭默认scrollWheelZoom/缩放动画，rAF合并最新锚点和累计轮量，通过公共setZoomAround(...,{animate:false})响应。保留边界、deltaMode、细轮残余与外部移动时reset；系统ctrl/meta和控件不被劫持，销毁取消事件和帧。marker池按ID与图层管理，高塔阈值和神庙显示开关只显隐；描述/选中/完成按变化更新，旧callback读current props；原最近中心规则和焦点不改。hover定位合并rAF，关闭/remove清理监听/observer/待帧。

底图重试先加载新概览，成功才替换旧可见概览；高清tile失败按坐标集合记录，tileload/卸载清理，提供紧凑提示和重试。失败不清掉仍可见底图、账号或进度。切页面/销毁清理旧层与事件。

验证：固定r3和r4相同16轮输入，区分首次视觉响应/完成状态更新/帧间隔；微benchmark不是本人GPU验收。高清做真实资产尺寸/hash与代表性地形视觉对齐，Pages路径、错误/重试、三语和DLC/点击/tooltip回归。原账号/真实API结果保持范围，不重复注册账号/SQL。当前本机修订，未发布。
