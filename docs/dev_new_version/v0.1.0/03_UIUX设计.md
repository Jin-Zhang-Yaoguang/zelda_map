# v0.1.0 UI/UX 设计

日期：2026-10-11。负责人：UI/UX 子代理。状态：可实现设计输入；尚未检查真实界面，不代表体验验收通过。

依据：[01_需求文档.md](01_需求文档.md)、[02_PRD.md](02_PRD.md)、[product_handoff.md](product_handoff.md)与项目约定。共同/角色记忆尚无既有记录，当前项目尚无可沿用的界面组件。

## 1. 方向与参考边界

这是神庙地图工具。首屏直接进入清晰海拉鲁全地图，搜索、筛选、完成进度围绕地图排布；不设营销首屏、装饰性大标题或功能介绍区。

用户指定 [Zelda Dungeon BOTW 互动地图](https://www.zeldadungeon.net/breath-of-the-wild-interactive-map/) 为主要参考。本轮直接读取返回403，未绕过限制，因此未宣称逐项核验参考站当前界面。采用需求明确的“真实底图、分类点位、搜索列表、点击预览、主动进入攻略”路径；底图/点位真实性由技术和QA核验。

视觉以真实底图为主，墨绿/石板侧栏和克制希卡蓝操作色承载工具。未完成标记为蓝色，已完成增加勾形和较柔和的绿色，选中标记加克制细外环；状态不放大图标，并同时有形状或文字区别。

## 2. 信息与页面

| 视图/入口 | 结构与主要操作 | 返回与保留 |
| --- | --- | --- |
| `#/` 地图 | 顶栏、搜索筛选列表、地图、所选神庙安全预览 | 默认全图；后续保留中心、缩放、查询、地区、完成筛选与有效选择 |
| `#/shrine/:id` 独立详情 | 返回地图、名称/地区/范围、基础介绍、完成按钮；详细依赖、物资、攻略各自折叠；来源 | 返回原地图上下文；恢复发起详情的链接/按钮焦点 |
| `#/settings` 独立设置 | 语言、DLC显示、浏览器保存说明、导出/导入备份 | 返回原地图上下文；若过滤后选择失效则不恢复预览 |
| 无效详情ID | “未找到这座神庙”与返回地图 | 不创建虚构内容，保留地图上下文 |

hash路由经技术角色确认适合本机静态预览，深链刷新仍可进入对应视图。独立详情/设置都有可辨认页面标题和返回入口，不以外部网页替代。

桌面（宽度≥900px）：72px顶栏，336px侧栏，剩余空间为地图。地图不被全屏内容卡遮住。详情/设置最大内容宽度960px，居中但不采用卡片堆叠营销布局。

```text
│ 地区⌄  完成状态⌄        │            海 拉 鲁 全 地 图           │
│ DLC显示 [开启]          │           可拖动、滚轮缩放             │
│ 结果 5/24 · 清除筛选    │                                      │
│ ─ 名称 · 地区 · DLC ─   │                     神庙点位          │
│ ─ 名称 · 地区 · 已完成 ─│                              [+]     │
│ ─ 可滚动神庙列表 ─      │                              [−]     │
│                        │                              [全图]   │
│ 所选安全预览           │                                      │
│ 名称 / 地区 / 范围      │                                      │
│ 基础介绍 / 简短前置     │                                      │
```

窄屏（宽度<900px）：56px顶栏，地图占满余下可视高度；底部面板承载列表与预览。宽度360px可用，44px触摸目标，左右留白16px。侧栏不缩成难点的小列。

```text

│       可拖动缩放地图        │
│                     [+][−] │
│                     [全图] │
```

手机底面板有两档：收起为56px工具条；展开最大为可用高度60%，内容内部滚动。选择神庙后自动展开预览，关闭预览回到列表；“收起面板”是按钮，拖拽手柄可选，不依赖手势。展开时不把焦点困在面板内；仅真正的导入确认对话框管理焦点。软键盘打开时搜索栏与清除按钮仍可触达。

## 4. 组件规格

| 组件 | 实现规格 |
| --- | --- |
| 顶栏 | 产品名短文字；当前范围进度；语言菜单用“中文 / English / 日本語”，不用国旗；设置按钮常见可见 |
| 搜索 | 明示标签“搜索神庙”；placeholder“名称或地区”；匹配三语名称/地区和已核实别名；清除按钮有独立名称；不检索详情 |
| 筛选 | 地区、全部/未完成/已完成、DLC显示；无须另点应用。显示当前结果已完成/总数，与范围进度分开 |
| 列表行 | 名称、地区、DLC徽标、完成图标；整行选中并定位地图，完成按钮单独操作并阻止触发定位；不含奖励或试炼解法 |
| 地图点位 | r2神庙可见图形16–20px，建议18px；触摸命中区≥44px。近景逐座显示真实点位，完全取消聚合、数字及附近分组；远景只显示高塔定位层，详见第10节 |
| 地图控件 | 放大、缩小、显示全图均为44px按钮，有可读名称。列表选择同时定位，作为拖动的键盘替代入口 |
| 安全预览 | 始终显示名称/地区/范围/完成；基础介绍与简短前置；坐标名称采用来源合同，如“地图坐标 X/Z”，不称经纬度；详情按钮是主入口 |
| 详情折叠区 | 详细依赖、物资、通关攻略独立按钮控制，默认关闭；状态同时暴露给辅助技术；一节展开不自动展开另一节 |
| 完成按钮 | 两态“标记完成”/“取消完成”；按下后立即同步点位、列表、预览、详情与计数；不显示虚构通关验证 |
| 来源/核实标签 | 来源显示站名及链接；详情外链标“外部参考，可能剧透”；暂译、待核实、缺译直接贴近字段，无假定空值 |

颜色建议：页面底色`#101C20`，侧栏`#17282D`，分隔`#34464B`，正文`#E8F0EF`，次文字`#BAC9C7`，操作蓝`#69D4F5`，完成绿`#95C9A8`。地图保持原图对比，不叠深色蒙版。基础字号16px，行高1.5；桌面标题22–28px。中文/英文/日文字体用系统无衬线并保留对应系统回退，不依赖联网字体。可点击文字/图形实际对比由浏览器QA核验。

## 5. 外层安全字段合同

外层包含地图标记的悬浮/焦点提示、列表、搜索结果和预览。只读取专用安全对象，不把`detail`截断、摘要后复用。

| 字段 | 外层呈现 |
| --- | --- |
| 稳定ID | 身份与路由使用，不作用户名称 |
| `name`、`region`、`scope`、`coordinates` | 三语名称、地区、本体/DLC、真实地图坐标 |
| `safe.summary` | 已核实的基础环境/一般用途；不含机关、隐藏入口操作或故事结果 |
| `safe.prerequisite` | 仅类别概述；可写需神庙挑战或DLC任务，具体操作/物品/答案均留详情 |
| `completed` | 读取当前浏览器完成ID集合 |
| `verification`、`translationStatus` | 待核实、暂译、缺译的明确标签 |

外层不显示试炼完整解法、详细任务名/过程、宝箱数量/位置/物品、奖励和攻略截图。空字段显示“待核实”；仅已核实无前置时可显示“无额外前置”。来源名可见，外层主要链接仍进入本站详情。进入详情、展开敏感区是清楚的主动动作。

## 6. 状态与恢复契约

| 动作/情况 | 行为与反馈 |
| --- | --- |
| 切换语言 | 当前视图即时变更全部可翻译字段；保留ID、中心/缩放、查询文本、地区ID、完成筛选、DLC偏好、折叠状态。选项名始终自称其语言。内容缺译显示提示再回退，不伪装完整 |
| DLC快速开关/设置开关 | 两入口共用同一持久偏好；地图、列表、搜索与范围分母同步136↔120。隐藏DLC不移除完成ID，重新开启恢复标记 |
| 关闭DLC且选中DLC | 地图清除预览与选中；若在详情则继续呈现并提示“DLC已在地图隐藏”，不跳页。返回地图按最新偏好过滤 |
| 更改筛选隐藏选择 | 清除外层预览；地图视角不跳回全图；顶部给轻量提示“所选神庙不在当前筛选内” |
| 标记完成后被未完成筛选排除 | 先保存，再移除当前结果/预览；状态区域反馈“已标记完成”；提供短时“撤销”按钮，撤销再写同一集合 |
| 返回地图 | 恢复中心、缩放、搜索与筛选；仍可见的选择恢复安全预览；返回焦点到发起入口，入口消失则到搜索。敏感详情区重新折叠 |
| 切换神庙详情/刷新深链 | 每座敏感区初始折叠；合法ID可查看，未知ID显示未找到。首次无地图上下文时返回默认全图 |
| 首次加载 | 地图/列表分别显示加载提示；预留顶栏、控件与列表结构；未取得数据不显示“0座” |
| 底图失败 | 明确“地图暂时无法加载”，给“重试地图”；列表、筛选和详情仍可使用，不展示空白地图当作成功 |
| 神庙数据失败 | 明确“神庙资料加载失败”，给“重试资料”；禁止虚假数量与失效操作，设置及已有进度导出仍可用 |
| 无搜索结果 | “没有符合条件的神庙”；展示当前查询/筛选摘要与“清除筛选”；不作数据错误提示 |
| 浏览器存储失败 | 常驻轻量提示“本次进度未能保存，可导出备份”；当前会话可操作；不提示保存成功，重试保存与导出入口可见 |
| 缺资料/缺译 | 字段旁标“待核实”或“缺少所选语言译文”；详情保留来源。无资料不等于无依赖/无物资 |

导出在设置页单击生成进度备份，包括隐藏DLC完成记录，反馈“备份已导出”。导入选择文件后先校验，预览当前完成数、备份有效完成数、未知ID数以及“将替换当前进度”；用户明确点击“恢复备份”才执行，取消无变化。未知ID列出可展开明细，说明不计入进度，不能静默丢弃。失败显示原因并提供重选。保留导入前备份并明确恢复入口，具体存储方式由技术合同确定。

## 7. 键盘与辅助技术

- 文档开头有“跳到神庙列表”“跳到地图控件”。Tab顺序依页面视觉顺序；所有按钮、选择和路由链接用语义元素。
- Enter选择列表/点位；Space或Enter操作完成、DLC和折叠按钮。Esc关闭安全预览或导入对话框；不触发完成状态。
- 地图容器获得焦点时方向键平移，`+`/`-`缩放；输入框焦点内不拦截按键。无方向键实现时必须以地区筛选、列表定位及缩放/全图按钮完成同样任务，QA据实际实现记录。
- 标记点的可读名称只含名称、地区、范围、完成状态；没有解法。可焦点点位过多时以列表为主要键盘选择面，不能制造136次无意义Tab。
- 路由切换焦点进入新视图标题；返回按第6节恢复。导入确认对话框聚焦标题/首操作，Tab不逸出，关闭后回到导入按钮。
- 保存失败和完成结果用非打断状态区域播报；错误表单关联具体提示。焦点环至少2px且不被容器裁掉。支持减少动态效果；定位平移不依赖动画理解。

## 10. r2 验收修订：远近两档显示

依据01的R8–R10/A8与2026-10-11用户反馈。两档先按**连续缩放、阈值切换显示层**设计；用户若选择两个固定级别，再修订此节。保留现有详情、设置、safe字段和神庙进度。

| 模式/操作 | 规则 |
| --- | --- |
| 远景 | 只显示15座真实Tower高塔点位，不渲染神庙标记。高塔不受神庙DLC/地区/完成筛选影响；神庙列表和进度仍遵守原筛选 |
| 近景 | 显示当前范围内逐座神庙；136座各有稳定ID，DLC关闭时120座；高塔层关闭。拖动/放大/缩小都不合并、拆分、偏移或产生聚合数字/附近分组 |
| 切换阈值 | 当前3000×2500底图、CRS.Simple下统一为`z=-1.0`：`z<-1`远景，`z≥-1`近景。保持滚轮、双指、按钮连续缩放，层在缩放完成后统一切换；QA验证边界及两层互斥 |
| 点击高塔 | 使用真实位置居中，缩放到近景（`NEAR_FOCUS_ZOOM=-0.5`，实际取`max(当前zoom, -0.5)`），方便就近查找神庙；不打开高塔详情、攻略或完成操作，不新增页面 |
| 列表选择神庙 | 立即选中同ID、居中并强制近景（同上）；手机中心按底面板以外的可见地图区域计算，标记不能定位后仍隐藏在远景或面板后 |
| 显示全图 | 回到全图并进入远景；若适配计算结果已越过阈值，则把zoom限制在阈值以下。返回详情的地图上下文仍按原规则恢复，不以全图覆盖 |
| 缩回远景 | 神庙列表选择/安全预览可保留，但所选神庙标记随神庙层隐藏；再到近景恢复其选中状态。远景提示说明此时看不到神庙点位 |

神庙视觉建议18px，圆/轮廓与内部图案减少笔画，完成用小勾，选中仅加细环；所有状态保持16–20px主图形，不叠大光圈、徽章数字或放大动画。44px命中区为透明交互范围，不能画成44px色块。高塔使用独立简洁塔形；重叠命中区按鼠标/触点离真实中心最近者命中，列表保持可定位，不用分组菜单替代。

远景地图小标签及高塔提示覆盖三语：

| 中文 | English | 日本語 |
| --- | --- | --- |
| 放大地图查看神庙 | Zoom in to see shrines | 拡大すると祠が表示されます |
